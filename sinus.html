Træning i Sinusrelationer

Angiv svaret med to decimaler

$$\frac{a}{\sin(A)} = \frac{b}{\sin(B)} = \frac{c}{\sin(C)}$$ eller $$\frac{\sin(A)}{a} = \frac{\sin(B)}{b} = \frac{\sin(C)}{c}$$
Opgave 1:Tegn en skitse af trekanten og find siden b

I trekant ABC er vinkel A = 40°, vinkel B = 60° og siden a = 10.

Opgave 2: Tegn en skitse af trekanten og find siden c

I trekant ABC er siden b = 12, vinkel B = 45° og vinkel C = 30°.

Opgave 3: Tegn en skitse af trekanten og find vinkel A

Siden a = 7, siden c = 10 og vinkel C = 80°. (Angiv i grader)

Opgave 4: Tegn en skitse af trekanten og find siden a

Vinkel A = 100°, vinkel C = 20° og siden c = 5.

Opgave 5: Tegn en skitse af trekanten og find siden c

Vinkel B = 45°, vinkel C = 105° og siden b = 8.

Advarsel: Sinusfælden!

Opgave 6: Tegn en skitse af trekanten og find vinkel C.

I en trekant er vinkel A = 30°, side a = 7 og side c = 10.
Da a < c, er der to mulige løsninger for vinkel C. Find dem begge.

hint: du kan bruge intervalsolve(...,C=0..180) for at få begge svar

Tegn igen en skitse og prøv at forklar hvordan der kan være to løsninger.
