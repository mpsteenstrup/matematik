Træning: Sinusrelationer & Fælder

$$\frac{a}{\sin(A)} = \frac{b}{\sin(B)} = \frac{c}{\sin(C)}$$

Opgave 1: Find siden $b$.
I trekant $ABC$ er $A = 40^\circ$, $B = 60^\circ$ og $a = 10$.

Opgave 2: Find siden $c$.
I trekant $ABC$ er $b = 12$, $B = 45^\circ$ og $C = 30^\circ$.

Opgave 3: Find vinkel $A$ (i grader).
$a = 7$, $c = 10$ og $C = 80^\circ$.

Opgave 4: Find siden $a$.
$A = 100^\circ$, $C = 20^\circ$ og $c = 5$.

Opgave 5: Find siden $c$.
$B = 45^\circ$, $C = 105^\circ$ og $b = 8$.

Advarsel: Sinusfælden!
